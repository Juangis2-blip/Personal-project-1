# Sistema de Acceso en Java

Mi primer proyecto personal en Java.

## Descripción

Programa sencillo de consola que solicita la edad del usuario
y determina si puede acceder a un evento.

## Conceptos utilizados

- Variables
- Scanner
- if
- else if
- else
- Operadores de comparación
- Operadores lógicos
- Entrada de datos por consola

## Ejemplo

El programa solicita:

Ingresa tu edad: 24

Y muestra:

Acceso permitido.
Bienvenido al evento.

## Tecnologías

- Java
